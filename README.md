# Fakebook - Red Social

## 📝 Descripción
Fakebook es una red social desarrollada como proyecto académico para la asignatura de **Despliegue de Sistemas Web Transaccionales en AWS**. La aplicación permite a los usuarios registrarse, publicar contenido, comentar, dar likes, enviar solicitudes de amistad y chatear en tiempo real.

---

## 🏗️ Arquitectura

| Capa | Tecnología | Servicio AWS |
|------|------------|--------------|
| **Presentación** | HTML/CSS/JS | EC2 (Node.js) |
| **Lógica** | Node.js (Express) | EC2 |
| **Datos** | MySQL | RDS |
